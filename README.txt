TECHNOVA HTML + CSS PROJECT

Files:
- index.html: homepage
- products.html: product catalogue
- product-details.html: featured product detail
- offers.html: offers page
- about.html: about and contact page
- css/style.css: shared styling

How to run:
1. Extract the TechNova folder.
2. Open the folder in Visual Studio Code.
3. Open index.html.
4. Right-click and choose "Open with Live Server", or open index.html in your browser.
5. Use the navigation menu to move between pages.

Notes:
- This project uses HTML and CSS only. There is no JavaScript or backend.
- Product images and Google Fonts load from the internet, so internet access is needed for those assets.
- Search, cart, and contact form are visual demonstrations only.
- Product descriptions, prices, and contact details are sample content for an institute project.
